# 課程海報提示詞工作室 · Poster Studio V2.1

繁體中文課程招生海報提示詞工具。填寫課程資料、搭配風格與版型示意，直接把提示詞貼到 ChatGPT。

線上站點：https://squall021.github.io/poster-generator/

## 使用流程

1. 選擇「產業人才投資計畫補助課程」或「自辦課程」。補助課程另填民國計畫年度，註記目前固定為下半年。
2. 選擇完整海報、無文字底圖或修改現有海報。
3. 填課程內容，選擇自由文字、固定每週、多梯次或分日課表，填寫費用與聯絡資訊。
4. 在「視覺風格」選擇風格卡，在「排版設定」選擇版型卡。右側即時顯示配色與區塊示意；風格和版型各自選擇，可自由搭配。
5. 在「設計補充」輸入個別要求。正式課程文字與必要註記會隨表單更新。
6. 核對右側正式文案，複製或下載提示詞。ChatGPT 生成後逐字核對。

提供三組明確標示的示範資料；日期、價格與內容都應換成正式課程資料。

## 風格與版型示意

- 9 種風格卡以原生 SVG 呈現配色、材質與圖形氣氛；6 種版型卡以區塊顯示標題、主圖和資訊位置。
- 風格名稱使用通用設計用語：柔和優雅、溫暖質感、清楚招生、極簡留白、活潑創意、沉穩紋理、鮮明醒目、動感筆刷、精緻光澤。提示詞描述與示意圖形亦避免綁定特定課程。
- 卡片與即時預覽僅供理解設計方向；主視覺內容依「主視覺與圖片元素」描述生成。分日版型依正式課程日數，不因示意圖而增加課程。
- 一般流程直接複製提示詞即可，風格與版型描述已寫入指令。
- 需要照片或既有設計作參考時，勾選「使用自己的參考圖」，填寫希望參考的部分，再自行於 ChatGPT 附圖。網站只儲存文字描述。
- 修改現有海報模式仍需於 ChatGPT 附上要修改的原海報。

## 補助／自辦分流

- 補助課程：左上角「廣告」、右上角依年度組成計畫名稱、正下方完整須知。
- 自辦課程：不加入三段註記，不帶入保留於草稿中的補助費用分項；有使用原圖或參考圖時，另明確指示不沿用其補助資訊。
- 底圖模式：只產生無文字圖像並保留註記空間，註記原文另列供後續排版。
- 修改模式：依本次課程類別保留、補齊或移除註記，年度依本次欄位更新。
- 缺少類別、課名（修改模式為修改內容）或必要年度時，不提供正式提示詞複製／下載。

須知原文依本專案使用者提供的範本保留，位於 `engine.mjs`；生成器不判定個別學員的補助資格。

## 儲存與舊版相容

- 草稿、命名設定與常用聯絡資料儲存在目前瀏覽器的 localStorage，不跨裝置同步。
- 使用 JSON 匯出備份或移到其他電腦；目前課程與常用聯絡資料一併匯出。
- 支援 V1 與 V2 JSON。V1 日期、費用、其他文案保留；課程類別留待使用者補選。
- 舊 V2 完成圖選擇的配色、風格、版型、主視覺描述及正式課程資料保留；不再啟用完成圖參考或要求附上舊圖。新加入的參考圖選項預設關閉。
- V1 手動提示詞保存成可查看／下載的原文備份，不作為新版正式輸出。
- 同一網站 origin 首次開啟 V2 時讀取 V1 草稿及命名設定，另存 V2；原 V1 storage keys 不刪除。
- 更新須知範本時以 `NOTICE_VERSION` 標記版本，舊版本草稿載入後提示核對。

清除瀏覽器資料會移除本機儲存。開啟本機預覽與原 GitHub Pages 屬於不同 origin，因此本機預覽無法直接讀取原站的草稿，請用 JSON 匯入。

## 本機啟動

需要 Node.js，無第三方套件與安裝步驟：

```sh
node dev-server.mjs
```

開啟 http://127.0.0.1:8000/ 。可用環境變數 `PORT` 改變埠號。也可以用一般 HTTP 靜態伺服器；ES modules 不適合直接以 file URL 開啟。

## 檢查

```sh
node --check app.mjs
node --check engine.mjs
node --check design.mjs
node --test tests/engine.test.mjs
```

測試涵蓋原文與位置、年度切換、三種模式、自辦分流、跨年課表、日期驗證、費用分項、V1／V2 遷移，以及無參考圖／自備參考圖兩種流程。

## 部署

維持 GitHub Pages：來源為 `main` 分支根目錄。發佈時包含 `index.html`、`style.css`、`app.mjs`、`engine.mjs`、`design.mjs` 與 `.nojekyll`；不需要圖片資產、建置、後端或 API 金鑰。

## 圖片與輸出範圍

風格卡、版型卡與預覽皆由本專案程式產生 SVG／CSS 示意，不含實際完成海報、課程照片或其聯絡資料。原始完成圖仍保留在專案上層的 `完成圖` 資料夾供內部設計參考，不放入網站或發佈包。

版面示意不是 AI 海報。網站不直接呼叫 ChatGPT，不上傳課程資料或本機檔案。生成提示詞不能保證圖像模型準確繪字；需要精確的長段須知時，使用底圖模式後另行排版。紙張設定不代表輸出已符合印刷解析度，正式使用前核對尺寸、文字、Logo 與 QR Code。
